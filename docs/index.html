Shinkansen Nozomi｜Firefox / Chrome 网页翻译扩展

Shinkansen 的 fork：追加 Firefox 双平台、Bing 第四引擎、三语界面、划区翻译
翻译请求由你的电脑直连 AI / 翻译 API，不经过任何第三方服务器

从 Firefox Add-ons 安装已上架 AMO · 推荐 GitHub 下载（含 Chrome）最新版 · 手动安装

开源 · 使用说明 · GitHub · fork 自 jimmysu0309/shinkansen

Nozomi 追加特性

  • Firefox 双平台支持：上架 Firefox AMO，与 Chrome 共用同一份代码编译出两个平台版本
  • Bing Translate 第四翻译引擎：在 Gemini / Google Translate / 自定义模型之外多一个免费选项
  • 三语用户界面：弹窗、设置页、提示文字全面支持 zh-TW / zh-CN / ja，跟随浏览器语言自动切换
  • 划区翻译：选中页面上任意文字即可即时翻译，无需整页翻
  • 统一 CJK 字体栈：zh-TW / zh-CN / ja / en 显示字体统一处理，避免日文网页被中文字体错误渲染

本页所有「上游既有」功能 — Gemini 直连、双语对照、YouTube 字幕、术语表、地区用语黑名单、费用透明、极速秒翻、Sticky 自动翻译 — 在 Nozomi 上同样完整保留。完整功能列表见下方

为什么做 Shinkansen？— 来自原作者

既有的沉浸式网页翻译工具会把你浏览的每一页内容传到第三方服务器——无论你读了什么文章、看了什么邮件，全部都可能被看光

Shinkansen Nozomi 继承上游的隐私优先理念：

数据不外传：翻译请求由你的电脑直连所选翻译 API（Gemini / Google Translate / Bing / 自定义模型），不经过任何第三方中继服务器
设置留在本地：所有数据只存在你自己的电脑上
源代码完全公开：任何人都可以查看代码，确认没有后门

功能特色

四翻译引擎 ★ Nozomi

Gemini + Google Translate + Bing Translate + 自定义模型（OpenAI 兼容端点，可接 OpenRouter / Together / DeepSeek / Ollama 本机等百种模型）并存，按场景自由切换

自定义快捷键 ★ Nozomi

三组可自定义快捷键（Alt+A / Alt+S / Alt+D），一键切换翻译引擎与模型

Firefox 双平台 ★ Nozomi

上架 Firefox AMO，Chrome / Firefox 同一份代码编译出两个平台版本，符合 Mozilla AMO 审核（零 innerHTML）

三语用户界面 ★ Nozomi

弹窗、设置页、提示文字全面支持台湾繁体（zh-TW）/ 简体中文（zh-CN）/ 日文（ja），跟随浏览器语言自动切换

划区翻译 ★ Nozomi

选中页面上任意文字即可即时翻译，弹出小卡片显示译文，无需整页翻

极速秒翻

按下翻译 1 秒就看到页面开始变中文，不用等整批 API 返回再一次塞回页面（限 Gemini）

保留网页排版

原地替换文字，字体、字号、颜色、链接全部保留，看起来就像原生中文页面

双语对照

原文与译文并列显示，一眼对照学语言或核对译文；单语覆盖与双语对照可随时切换

YouTube 字幕翻译

看 YouTube 视频时，英文字幕自动翻译为中文

跨页自动延续翻译

翻译过的页面点链接开新标签、按返回键回上一页都自动翻译，不用每页再按一次

固定术语表

自定义翻译对照表，确保专有名词一律使用你指定的译名

地区用语黑名单

可编辑的禁用词清单（默认 25 条，涵盖 视频 / 软件 / 数据 / 网络 / 质量 / 用户 等繁中地区视为陆词的常见词），译至繁中场景明确要求 LLM 不使用

只翻文章开头

先翻前几段预览再决定是否读完整篇，大幅节省 token

翻译缓存

翻过的段落自动缓存，同一页再开不花钱

费用透明

每次翻译实时显示花费多少钱，设置页可回查过去每一笔翻译记录的 token 用量与费用，支持图表与 CSV 导出

安装步骤

Firefox 用户：直接点上方「从 Firefox Add-ons 安装」按钮，AMO 一键安装，跳到第 3 步设置 API Key 即可

1

下载并解压（Chrome 用户）

从上方「GitHub 下载」按钮下载 shinkansen-chrome-vX.Y.Z.zip，解压到任意位置

2

加载扩展（Chrome 用户）

打开 Chrome，访问 chrome://extensions/，打开右上角「开发者模式」，点「加载已解压的扩展程序」，选择解压后的 shinkansen 文件夹

3

设置 API Key（共通）

点工具栏的 Shinkansen 图标 → 设置 → 粘贴你的 Gemini API Key完成！三组快捷键 Alt+A / Alt+S / Alt+D 对应可自定义的翻译预设；其中 Google Translate 与 Bing 引擎免 API Key 即可使用
